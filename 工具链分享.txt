裁剪，从11分48秒开始裁剪16秒的时间，即裁剪00:11:48-00:12:04这一段视频，导出视频并命名为output.mp4。自动匹配mp4格式协议。
ffmpeg -i E:\OBS\video\2024-11-20_11-57-05.mp4 -ss 00:11:48 -t 00:00:16 -c:v copy -y output.mp4
通过复制来提取单独的视频（不含音频）：
ffmpeg -i input.mp4 -vcodec copy -an out.mp4
不解编码，通过复制覆盖来合并单独的视频和音频
ffmpeg -i video.m4s -i audio.m4s -vcodec copy -acodec copy output.mp4
转格式
ffmpeg -i output1.avi output1.mp4
ffmpeg -i infilename.avi -c:v copy -c:a copy -y outfilename.mp4
循环视频至音频结束
ffmpeg -stream_loop -1 -i F:\ bg_ani_pc.mp4 -i F:\ bgm_Bu7lyqVS.mp3 -vcodec copy -acodec copy -t 00:01:15 new.mp4
webm转mov：
ffmpeg -i助手.webm -pix_fmt yuv422p10le -c:v prores -profile:v 3 -vendor ap10 output.mov
